# WebCraft

- [Play WebCraft](https://nhahan.github.io/webcraft/)
- [Asset gallery](https://nhahan.github.io/webcraft/#assets)

이 저장소는 **배포 전용**입니다. 빌드 결과물(`index.html`, `assets/`)만 들어 있고 GitHub Pages가 서비스합니다.
소스 코드와 빌드·테스트는 구현 저장소 [Nhahan/webcraft-standalone](https://github.com/Nhahan/webcraft-standalone)에 있습니다.
여기서 직접 고치지 말고, 구현 저장소에서 `npm run build`로 만든 `original/standalone-web/dist/`를 덮어써 배포합니다.
